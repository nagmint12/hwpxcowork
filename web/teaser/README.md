# hwpx-cowork 소개 영상(코드 재생판)

20초 소개 영상을 **영상 파일 없이 코드로** 재생합니다. 화면은 실제 hwpx-cowork 화면을 찍은 그림 8장(`assets/`)이고, 카메라 이동·자막·커서·타이핑은 `film/` 의 장면 코드가 시각 t 로 그립니다. 소리는 없습니다(무음).

## 넣는 법

1. 압축을 프로젝트 폴더(`<repo>`)에 풀면 `web/teaser/` 가 생깁니다.
2. 서버는 `web/` 를 그대로 내보내므로(`server/index.js` 의 `app.use('/', express.static(web))`) 따로 고칠 것이 없습니다.
3. `http://localhost:<포트>/teaser/` 로 열어 확인합니다.

## 첫 접속 소개

> 첫 접속에서는 `web/teaser3/`(여백의 손글씨) 다음에 이 기능 소개 영상이 이어진다. 로그인 화면의 ‘소개 영상 다시 보기’로 두 영상을 다시 볼 수 있다.
> 아래 소개 모드(`?intro=1`)는 이 영상에도 그대로 남아 있다.

(옛 동작) `web/index.html` 머리의 짧은 스크립트가 이 브라우저의 첫 접속(localStorage `hwpx-cowork.teaserSeen` 없음)이면 `/teaser/?intro=1&next=<원래 주소>` 로 보냈다. 표시는 보내기 전에 남기므로 중간에 닫아도 다음엔 다시 나오지 않는다.

- 소개 모드: 한 번만 재생하고 끝나면 `next` 로 간다. 화면 누름으로 멈추지 않는다.
- 바로 넘어가기: 오른쪽 위 '건너뛰기', Esc·Enter·스페이스, 또는 클릭·키·휠이 2초 안에 3번 이상.
- 건너뜀: 자동화 브라우저(`navigator.webdriver` — 화면 시험), 주소에 `?teaser=0`, 저장소를 못 쓰는 브라우저.
- `next` 는 같은 사이트 경로(`/…`)만 받는다(`//`·`/\`·바깥 주소는 `/` 로).
- 다시 보려면 브라우저에서 `localStorage.removeItem('hwpx-cowork.teaserSeen')` 또는 `/teaser/` 를 직접 연다.

## 다른 화면에 끼워 넣기

```html
<iframe src="/teaser/" title="hwpx-cowork 소개" loading="lazy"
        style="width:100%;aspect-ratio:16/9;border:0;border-radius:12px"></iframe>
```

주소 옵션(함께 쓰려면 `&` 로 잇기)

| 옵션 | 뜻 |
|---|---|
| `?autoplay=0` | 멈춘 채로 시작(첫 화면이 포스터) |
| `?loop=0` | 끝 화면에서 멈춤(기본은 반복) |
| `?controls=0` | 재생 막대 숨김(배너처럼) |
| `?t=7.5` | 그 시각부터 시작 |

예: 문서함 위 배너 → `/teaser/?controls=0`

크기: 단독으로 열면 PC 화면(폭 900px 이상)에서는 가로 8%·세로 10% 여백을 둔 둥근 틀로 띄우고 원래 크기(1920×1080)보다 키우지 않습니다. 모바일 등 좁은 화면과 iframe 안에서는 16:9 비율대로 가득 채웁니다(`player.js` 의 `fit`, `mount(el, { frame })`).

조작: 화면을 누르거나 스페이스 키 = 재생/일시정지, ←/→ = 2초 이동, 아래 막대 = 원하는 시각으로 이동. 재생 막대는 평소 숨겨 두고, 화면 아래 막대 자리에 마우스를 올렸을 때만 보입니다(멈춘 동안에도 같음). 소개 모드에서는 막대 조작을 연타로 세지 않습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 재생 페이지(무대 16:9 맞춤, 재생 막대) |
| `player.js` | 재생기 — 장면 모듈을 불러 `render(t)` 로 그림, 자동재생·반복·이동 |
| `film/scenes.json` | 장면 순서와 길이(문서가 열린다 3.5초 · AI 제안 6초 · 함께 검토 5초 · 마무리 5.5초) |
| `film/base.css` | 색(UIC 발표양식: #001A70 · #F5A800 …)과 공통 모양 |
| `film/shared.js` | 실제 화면 그림 위의 카메라·커서·상태 바뀜 도우미(`window.UI`) |
| `film/scene-*.js` | 장면 4개 |
| `assets/ui-*.webp` | 실제 화면(1600×900 화면을 2배로 찍음) — 본문, 요청 입력, 대기열, 제안, 메모, 반영 후, 한글로 저장 |

## 바꾸는 법

- **문구**: 자막은 `scene-propose.js`·`scene-review.js` 의 `class="cap"`, 제목·마무리 문구는 `scene-open.js`·`scene-end.js` 에 있습니다.
- **길이**: `scenes.json` 의 `dur` 와 해당 장면 안의 시각(초)을 함께 고칩니다.
- **화면 그림 교체**: 같은 이름, 같은 배치(1600×900 창, AI 작업 창 열림, 본문 4쪽)로 다시 찍어 바꾸면 커서·카메라 좌표가 그대로 맞습니다. 배치가 달라지면 장면 파일의 좌표(1600×900 기준)를 고칩니다.

## 알아 둘 점

- 화면 그림 속 문서 「결과보고서」, 사용자 「신연구」·「김검토」는 표준서식으로 새로 만든 가상 자료입니다(data/ 의 실제 문서는 쓰지 않음). 체험용 서버(`HWPX_COWORK_AI=off`, 임시 data 폴더)에서 Claude Code 연결(MCP)로 요청을 처리해 찍었습니다.
- 자막 글꼴은 Pretendard → 맑은 고딕 순으로 씁니다(앱 `--font` 와 같은 순서).
- 바깥 라이브러리·네트워크를 쓰지 않습니다. 전체 크기 약 1.3MB.
