# hwpx-cowork 소개 영상 — 여백의 손글씨(코드 재생판)

약 30초 영상을 **영상 파일 없이 코드로** 재생합니다. 앞부분은 한 장의 보고서 여백에 세 사람(연구원·검토자·조교)의 AI 메모가 손글씨로 쌓이는 장면이고, 종이가 하얗게 바래면서 실제 hwpx-cowork 화면 시연(그림 6장)으로 넘어갑니다. 소리는 없습니다(무음).

| 장면 | 길이 |
|---|---|
| 한 장의 보고서 | 4.5초 |
| 여백의 손글씨 | 6초 |
| 문장 위에서 | 4초 |
| 실제 화면에서 | 10초 |
| 마무리 | 5초 |

## 넣는 법

1. 압축을 프로젝트 폴더(`<repo>`)에 풀면 `web/teaser3/` 가 생깁니다. 첫 번째 영상(`web/teaser/`)·두 번째 영상(`web/teaser2/`)과 따로 있으므로 함께 둘 수 있습니다.
2. 서버가 `web/` 를 그대로 내보내므로 서버 코드는 고칠 것이 없습니다.
3. `http://localhost:<포트>/teaser3/` 로 열어 확인합니다.

## 별도 소개 영상(2026-11-13)

첫 접속은 `/teaser/` → `/onboarding.html` 순서다. 이 영상은 `/teaser3/` 직접 주소로 남겨 둔다.
이전에 저장된 `hwpx-cowork.teaser3Seen` 방문 기록도 `web/intro.js`에서 존중한다. 시작 안내는 서버 설정이나 토큰별 튜토리얼 완료 상태를 바꾸지 않는다.

- 소개 모드: 한 번 재생하고 기능 소개 영상으로 이어진 뒤 `next` 로 간다. 화면 누름으로 멈추지 않는다. '동작 줄이기'가 켜져 있어도 재생한다(멈춘 채면 넘어가지 않으므로).
- 바로 넘어가기: 오른쪽 위 '건너뛰기', Esc·Enter·스페이스, 또는 클릭·키·휠이 2초 안에 3번 이상.
- 건너뜀: 주소에 `?teaser=0`, 이전 방문 표시 또는 저장된 접속 토큰이 있는 브라우저. 자동화 여부나 IP로 생략하지 않는다.
- 저장소가 차단된 브라우저도 영상을 보여 준다. 돌아오는 주소에만 `teaser=0`을 붙여 무한 이동을 막는다.
- `next` 는 같은 사이트 경로(`/…`)만 받는다(바깥 주소는 `/` 로).
- 단독으로 열면 PC 화면에서 여백을 둔 둥근 틀로, 다른 화면 안(iframe)에서는 상자를 가득 채운다(`mount(el, { frame })`).
- 이 영상을 소개 모드로 직접 열면 종료 시 `/teaser/`와 시작 안내로 이어진다. 이 영상의 건너뛰기는 원래 주소로 돌아간다.
- 로그인 화면의 ‘소개 영상 다시 보기’는 `/teaser/`와 시작 안내를 연다.

## 다른 화면에 끼워 넣기

```html
<iframe src="/teaser3/" title="hwpx-cowork 소개 — 여백의 손글씨" loading="lazy"
        style="width:100%;aspect-ratio:16/9;border:0;border-radius:12px"></iframe>
```

| 주소 옵션 | 뜻 |
|---|---|
| `?autoplay=0` | 멈춘 채로 시작 |
| `?loop=0` | 끝 화면에서 멈춤(기본은 반복) |
| `?controls=0` | 재생 막대 숨김(배너처럼) |
| `?t=14.5` | 그 시각부터 시작(14.5초 = 실제 화면 시연 시작) |

조작: 화면을 누르거나 스페이스 = 재생/일시정지, ←/→ = 2초 이동, 아래 막대 = 위치 이동. 운영체제의 '동작 줄이기'가 켜져 있으면 멈춘 채로 시작합니다.

## 바꾸는 법

- **손글씨·자막 문구**: 손글씨 문장은 `scene-page.js`·`scene-hands.js`·`scene-meet.js` 의 `class="hand"`, 메모 세 개는 `shared.js` 의 `HW.NOTES`, 시연 자막은 `scene-demo.js` 의 `DEMO_CAPS`, 마무리는 `scene-end.js`.
- **실제 화면 그림 교체**: 같은 배치(1600×900 창, 메모 탭, 본문 4쪽 스크롤 3650)로 다시 찍어 같은 이름으로 바꾸면 커서·카메라 좌표가 그대로 맞습니다.

## 알아 둘 점

- 첫 번째 메모는 「‘보인다’ 말고, 적절한 표현으로」, 실제 화면의 Claude Code 제안 이유도 「‘보인다’ 대신 적절한 표현으로」입니다.
- 세 번째 고침 글은 손글씨 장면과 실제 화면 모두 「이러닝시스템」입니다(「학과 공동 자료실」 → 「이러닝시스템」).
- 화면 속 문서 「결과보고서」와 사용자 신연구·김검토·이조교는 가상 자료이며, 체험용 서버에서 각자 Claude Code·ChatGPT·Codex 로 MCP 에 연결해 실제로 제안·메모를 남겨 찍었습니다.
- 바깥 라이브러리·네트워크를 쓰지 않습니다. 전체 크기 약 2.3MB.
