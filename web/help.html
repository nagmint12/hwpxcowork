# GitHub에서 HWPX Cowork 받기·설치

현재 작업 폴더에 HWPX Cowork를 설치하고 시작해 주세요. 프로그램 파일은 아래 공식 GitHub 저장소에서 직접 내려받아 주세요.

https://github.com/nagmint12/hwpxcowork

- 운영 방식: [개인용 / 공동 작업용]
- 구독 AI: [Codex / Claude Code / 연결 안 함]

1. 운영 방식과 구독 AI를 각각 하나씩 사용하세요. 선택이 비어 있거나 여러 개면 그 항목만 먼저 물어봐 주세요.
2. Git이 있으면 `git clone --depth 1 https://github.com/nagmint12/hwpxcowork.git hwpxcowork`로 파일을 받아 주세요. Git이 없으면 같은 저장소의 기본 브랜치 소스 ZIP을 GitHub에서 받아 새 하위 폴더에 압축을 풀어 주세요. 같은 이름의 폴더가 이미 있으면 다른 빈 폴더를 사용하세요. 저장소에 접근할 수 없으면 다운로드 오류를 알려 주세요.
3. 받은 저장소의 README.md와 AGENTS.md를 읽고, 그 폴더에서 공식 설치 도우미를 실행해 주세요. Windows는 `.\scripts\setup-user.bat --mode MODE --ai AI --start`, macOS·Linux는 Node.js 22 이상으로 `node scripts/setup-personal.mjs --mode MODE --ai AI --start`를 사용하세요. MODE는 개인용이면 `personal`, 공동 작업용이면 `shared`입니다. AI는 `codex`, `claude-code`, `none` 가운데 하나이며, 구독 AI를 고른 경우에만 `--install-cli`를 추가하세요. 기존 설치와 설정·문서는 보존해 주세요.
4. 구독 로그인이나 계정 동의가 필요하면 제가 직접 할 수 있게 알려 주세요. API 키나 유료 API로 대신 연결하거나 확인용 모델 호출을 하지 말아 주세요.

설치 후 도우미에 선택한 `--mode`와 `--status`를 전달해 준비 상태를 확인하고 접속 주소를 알려 주세요. AI를 골랐다면 로그인과 연결 준비 상태도 알려 주세요.
직접 설치하기내 PC에 앱 설치 기존 서버에 접속서버 주소와 접속 토큰 AI에게 맡기기요청 · 결과 확인 · 반영

문서함과 권한

문서함 구분과 권한 자세히 보기

공용은 함께 쓰는 곳, 개인은 내 문서가 있는 곳, 공유받은 문서함에는 다른 사람이 내게 공유한 문서가 모입니다.

  • 보기 읽기·메모·AI 요청 · 작성 올리기·폴더 만들기 · 편집 고치기
  • 삭제 지우기 · 관리 권한·이름 바꾸기, 옮기기

어느 문서함이든 새 폴더, HWPX 올리기, 새 문서로 시작을 씁니다(같은 이름이 있으면 뒤에 (2)를 붙입니다). 문서 이름은 목록의 ✎ 또는 문서 화면 맨 위 이름을 눌러 바꿉니다.

공용 문서함 폴더는 상위 폴더 따름(위 폴더 권한 그대로) 또는 직접 지정(적은 사람만)입니다. 맨 위 권한은 관리자가 정합니다.

개인 문서함 폴더의 권한에 사람을 더하면 그 사람에게 공유됩니다. 문서 하나만 다르게 하려면 문서 줄의 권한 → 직접 지정. 관리자는 언제나 볼 수 있습니다.

볼 권한이 없는 문서는 목록과 AI 연결(MCP)에서도 보이지 않습니다. 문서 설정(⚙)의 수정 권한은 편집 권한이 있는 사람 가운데서 다시 고르는 것입니다.

AI에게 맡기기

AI 작업 → 확인 필요에서 제안을 읽고 반영 또는 거절을 누릅니다.

요청·첨부·진행 상태

다듬기·표 넣기·서식·비교할 안을 지시에 적고 자료는 첨부로 올립니다. AI에게 빠르게 맡기기(보라 ✦)는 누르면 바로 보냅니다.

진행 상태는 대기열 → 전달됨 → 처리 중 → 확인 필요 → 완료 순으로 표시됩니다.

고치기·메모·자동 반영

고치고 잠시 멈추면 저장되고 다른 사람 화면에도 보입니다. 문서 설정이 승인 후 반영이면 내 수정본에서 고친 뒤 검토를 받습니다. 의견은 우클릭 → 메모.

빠르게 맡기기 전에 예시 지시를 보고 싶으면 ⚙ 문서 설정 → AI에게 빠르게 맡기기 → 확인 후 보내기. 작업이 끝날 때 권장안을 바로 넣으려면 AI 자동 반영 → 자동 반영(되돌릴 수 있음). 수정안은 기본 1개, 비교가 필요하면 지시에 “세 가지 안으로”처럼 적습니다.

작업 기록과 제안의 자리

처리 중에는 AI 작업에 AI가 지금 하는 일(문서 읽기·수정 제안 등)이 한 줄로 보이고, 작업 기록 n을 펼치면 차례대로 봅니다. 문서 글과 지시 내용은 기록에 나오지 않습니다.

제안의 주소 칩(s0/p12 — 구역 / 위에서부터 센 문단 차례)을 누르면 그 문단으로 갑니다. 넣기 제안은 반영 전에는 이 문단 뒤에 새 문단, 반영 뒤에는 넣은 문단을 가리키고, 그 문단이 지워졌으면 자리 없음으로 보입니다.

차례 만들기

도구 → 차례/색인 → 차례 만들기는 한글과 같습니다. 개요 문단(또는 고른 스타일, 제목 차례 표시)으로 제목 차례를, 캡션으로 표·그림·수식 차례를 만들고 쪽 번호와 하이퍼링크를 답니다. 필드로 넣기로 만든 차례는 차례 안에서 우클릭 → 차례 새로 고침(또는 모든 차례 새로 고침)으로 다시 맞추고, 차례 고치기…로 선택 사항을 바꿉니다. 빼고 싶은 개요 문단은 차례 숨기기. 위치를 현재 문서의 새 구역으로 고르면 커서 문단 뒤에서 구역을 나눠 차례만 든 쪽을 만듭니다. 차례를 없애려면 끌어 골라 지웁니다.

버전과 한글로 저장

버전은 문서를 올릴 때, 변경 요청을 반영할 때, 이력 탭의 버전 저장으로 생깁니다. AI 작업은 시간이 좀 지난 뒤의 작업에서만 버전을 남깁니다. 이전 버전은 이력 탭에서 받거나 되돌리고, 최종 파일은 상단 한글로 저장으로 받습니다.

화면 넓게 쓰기

화면은 문서와 오른쪽 AI 작업 창 두 칸입니다. 메모·AI 작업·제안은 문서 옆 여백에 뜹니다. 메모 머리 줄을 끌면 옮기고, 두 번 누르거나 ↺로 제자리로 돌립니다(모두: 보기 → 메모 제자리로).

오른쪽 끝 AI 작업 꼭지로 창을 접고 고정합니다. 접어 둔 동안 오른쪽 끝에 마우스를 대면 잠깐 펼쳐집니다. 메모 꼭지는 문서 옆 메모를 숨기거나 보입니다. 경계선을 끌어 폭을 바꿉니다(두 번 누르면 기본 폭).

휴대전화처럼 좁은 화면에서는 문서 설정·사용 설명서·보기·한글로 저장이 ⋯ 메뉴에 들어가고, 메모는 아래쪽 창의 메모 탭에서 봅니다. 편집 도구 막대는 ⋯ → 편집 도구 막대.

서버 주소와 연결 순서

연결 준비 상태를 확인하는 중입니다…

ChatGPT에 등록할 서버 주소https 주소 확인 필요
  1. ChatGPT 플러그인 → ＋ → 사용자 지정 MCP 서버 추가.
  2. 이름 HWPX 공동 검토, 서버 URL은 위 주소, 인증 OAuth(등록 방식을 물으면 DCR, Client ID·Secret은 비움).
  3. 연결 → 이 서버의 확인 화면에서 내 토큰으로 허용.
ChatGPT에 붙여넣을 내용짧게는 “대기열을 처리해 줘”, 자세히는 아래 프롬프트
✦대기열 처리 프롬프트HWPX를 연결한 채팅
HWPX 공동 검토에서 내 대기 요청을 처리해 줘. task를 인자 없이 불러 가장 오래된 요청부터 하나씩 맡고, 함께 온 지시·대상·주변 글을 보고 필요한 범위만 read로 읽어 줘. 수정 제안과 의견은 edit 한 번에 모아 남기고 done에 짧은 공유 요약을 적어 완료해 줘. 고칠 것이 없으면 finish에 확인한 범위와 사유를 적어 끝내 줘. 수정안은 기본 1개, 비교를 요청한 경우에만 여러 안을 만들어 줘. 본문에 직접 반영하지 마. CLAIMED·NOT_OWNER·REQUEST_CLOSED·ATTEMPT_CHANGED 오류가 나면 그 요청은 건너뛰어 줘. task가 none을 돌려주면 몇 건을 처리했는지 알려 주고 끝내 줘.

claude.ai 같은 다른 웹 AI도 사용자 지정 커넥터에 같은 주소를 넣고 내 토큰으로 허용하면 같습니다.

이 주소는 작업 도구 넷(task·read·edit·finish)으로 연결됩니다. 예전 도구(claim_next_request·complete_request)를 쓰던 프롬프트는 위 MCP 서버의 예전 연결 주소로 연결합니다.

내 ChatGPT 연결 보기·끊기

같은 서버에 내 토큰으로 로그인한 뒤 연결 목록을 보거나 끊습니다. 끊으면 그 연결은 바로 쓸 수 없습니다.

③ 선택 · 유료

내 AI 키로 처리하기(API)

설치 없이 서버가 내 API 키로 바로 처리합니다. 구독과 별도로 쓴 만큼 API 요금이 듭니다.

API 키 등록·삭제 자세히 보기
  1. API 제공업체에서 키를 발급합니다.
  2. 문서 목록의 내 AI 키 → 키 붙여넣기 → 저장 → 연결 확인. 모델은 기본값으로 둘 수 있습니다.
  3. 그만 쓰려면 키 삭제.

키는 서버에 암호화해 둡니다. 연결 확인과 모델 목록에는 요금이 들지 않습니다.

내 PC 폴더에서 쓰기(개인용 앱)

연결한 폴더는 개인 문서함에서 PC 표시로 보입니다.

자세히
  • 한글에서 그 파일을 고쳐 저장하면 앱이 다시 읽습니다. 양쪽에서 고쳤으면 PC 파일이 기준이고, 앱에서 고친 내용은 이력 탭에 남습니다.
  • 한글에서 열어 둔 동안에는 쓰지 못합니다(PC 쓰기 대기). 한글에서 닫으면 저장합니다.
  • 새 문서·올리기·이름 바꾸기·옮기기·폴더 만들기는 PC 폴더에 그대로 반영됩니다. 지운 문서의 파일은 휴지통으로 갑니다.
  • 탐색기에서 옮기거나 이름을 바꿔도 내용이 같으면 같은 문서로 이어집니다. 연결 끊기는 문서함에서만 뺍니다.
  • 검토 서버에 함께 쓰는 서버의 주소와 그 서버의 내 토큰을 한 번 등록합니다. 검토본은 그대로(변경 추적·메모까지) 또는 최종본(변경을 모두 받아들인 글)으로 가져옵니다.

Windows용 Hwpx Cowork를 설치한 뒤 첫 실행에서 혼자 쓰기를 선택하세요.

문제가 생겼을 때

요청이 계속 ‘대기열’·‘전달됨’에 있어요

처리할 AI가 켜져 있지 않습니다. 내 PC의 Codex·Claude Code 실행기(Windows 앱은 AI → 실행기 관리…)나 채널을 켜거나, 대화창에서 “대기열을 처리해 줘”라고 하세요(① 내 PC의 AI). 내 연결 상태 확인으로 볼 수 있습니다.

토큰이 없다고 나와요

setx는 새로 연 창부터 보입니다. VS Code와 터미널을 완전히 닫았다 다시 엽니다.

MCP 등록에서 이미 있다고 나와요

예전 설정이 남아 있습니다. claude mcp remove hwpx -s user 또는 codex mcp remove hwpx 뒤 다시 등록합니다.

AI가 완료했는데 문서 글은 그대로예요

완료는 제안이 준비됐다는 뜻입니다. AI 작업 탭에서 반영을 눌러야 문서에 들어갑니다.

다른 AI가 이미 처리 중이라고 나와요

요청 하나는 한 곳에서만 처리합니다. 잠시 기다리세요. 처리하던 쪽이 끊겼으면 시간이 지난 뒤 다시 가져갈 수 있습니다.

중앙 PC는 문서·메모·제안·대기열을 보관하고 브라우저와 AI 연결을 받습니다. 참여자에게는 서버 주소와 서로 다른 개인 토큰을 전달하세요.

  2. config.example.json을 참고해 config.json에 참여자별 이름·역할·토큰을 설정합니다(웹 상단 관리자 → 사용자에서도 됩니다).
  3. 다른 PC의 접속을 받으려면 host를 0.0.0.0으로, publicUrl을 실제 공유할 주소로 맞추고 서버를 다시 시작합니다.
  4. 아래 공유 주소 점검으로 주소 후보를 보고, 다른 PC의 브라우저에서 실제 접속을 확인합니다.

같은 사무실 예: http://중앙PC의_IP:8787. 다른 지역에서는 HTTPS 주소나 VPN을 준비합니다. 주소 후보가 보인다고 외부 접속이 확인된 것은 아닙니다.

외부 주소·ChatGPT 연결(OAuth)을 준비할 때

사설 VPN·Tailscale Serve로 연결하거나, 인터넷 공개에는 Tailscale Funnel·정식 Cloudflare Tunnel·HTTPS 프록시를 씁니다. Cloudflare Quick Tunnel은 실시간 알림 연결을 유지하지 못하므로 자동 처리용 주소로 쓰지 마세요. 실행 터미널에서 $env:HWPX_COWORK_PUBLIC_URL = 'https://실제_서버_주소'로 주소를 지정할 수도 있습니다.

ChatGPT·claude.ai 연결에는 공개 HTTPS 주소가 필요합니다. 관리자 → 서버 접속 → 외부 공유 주소를 실제 HTTPS 주소로 저장하고 재시작하면 OAuth(DCR·PKCE S256)가 켜집니다. HTTP IP 주소에서는 꺼집니다. 콜백 주소가 기본 허용 목록과 다르면 config.json.oauth.redirectUris에 추가하고 재시작합니다.

참여자 토큰은 권한을 가진 접속 정보입니다. 공개 링크나 문서 본문에 넣지 마세요. 문서와 수정 이력은 중앙 PC의 data 폴더에 저장됩니다.
