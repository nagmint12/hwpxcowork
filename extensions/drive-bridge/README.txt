Cowork 두레이 드라이브 연결 (개발용 0.6.0, Chrome·Brave)

1. ZIP을 별도 폴더에 풉니다.
2. chrome://extensions 또는 brave://extensions 에서 개발자 모드를 켜고 '압축해제된 확장 프로그램을 로드합니다'로 이 폴더를 선택합니다.
3. 같은 브라우저에서 cowork 에 로그인한 화면을 연 채로 확장 아이콘을 누르고 [이 cowork 서버에 연결]을 누릅니다.
   처음 한 번 그 서버 접근을 허용합니다. 코드·주소를 입력하지 않습니다(그 탭에서 받은 한 번 쓰는 코드로 연결하며, cowork 토큰은 탭 밖으로 나오지 않습니다).
4. 다른 브라우저에서 연결할 때만: cowork 드라이브 → 연결 설정 → 코드로 연결에서 코드를 받아 확장 아이콘의 [코드로 연결]에 입력합니다.
5. 연결 후 창을 닫아도 백그라운드에서 동작합니다. 브라우저는 실행 중이어야 합니다. 서버를 다시 켜도 연결이 유지됩니다.
6. 같은 브라우저에서 두레이에 직접 로그인하고 본인의 개인 프로젝트를 열어 둡니다. cowork 드라이브에서 새로고침을 누르면 주소의 프로젝트 ID와 API의 개인 드라이브 여부를 확인하여 지금 cowork 사용자에게 연결합니다. 확장은 SSO 확장과 통신하지 않습니다.

업데이트: 기존 설치 폴더에 새 파일을 덮어쓰고 확장 관리 화면에서 Cowork 확장의 새로고침을 누릅니다. 확장 아이콘에서 연결 상태를 확인하고 필요하면 [이 cowork 서버에 연결]을 다시 누르세요.
별도 실행 창은 필요 없습니다. '연결 상태' 화면은 필요할 때 열고 닫을 수 있습니다.
서버 주소는 HTTPS 또는 localhost/127.x/10.x/172.16~31.x/192.168.x 사내망 HTTP를 지원합니다. 연결할 서버 하나에 대해서만 접근 권한을 요청합니다.
코드 등록 후 실제 백그라운드 통신을 확인해야 '연결됨'으로 표시합니다.
두레이 탭이 없으면 작업용 탭을 비활성 상태로 열고 작업 뒤 닫습니다. 사용자가 이미 열어 둔 탭이나 직접 선택한 탭은 닫지 않습니다.
로그인이 만료되면 cowork의 '연결된 브라우저에서 두레이 열기'로 직접 로그인하세요. 로그인 정보는 서버로 보내지 않습니다.
ngrok 요청에는 ngrok-skip-browser-warning 헤더를 사용하며 HTML 응답을 명확한 연결 오류로 표시합니다.

파일 탐색: 연결하면 폴더가 자동으로 열립니다. 파일을 선택해 업로드·다운로드·문서함으로 가져오기를 실행합니다.
HWPX를 더블클릭하면 개인/공용 문서함과 폴더를 고르고 '가져와서 열기'로 편집기에 들어갑니다. 문서함의 작성·공유 권한을 그대로 따릅니다.
'문서함 문서 올리기'에서는 읽을 수 있는 문서만 현재 두레이 폴더에 올릴 수 있습니다.
완료한 직접 전송의 임시 사본은 정리하며 기존 보관 파일·원격 원본·문서함 문서는 유지합니다.

개인정보: 폴더 목록은 요청한 내 화면에만 보입니다. 서버는 목록을 건네주기만 하고 저장하지 않으며, AI는 드라이브 폴더 목록을 알 수 없습니다.
가져오기·업로드·교체·삭제(휴지통으로)·이름 바꾸기는 cowork 화면에서 본인이 직접 할 때만 실행합니다. AI는 드라이브 작업을 요청할 수 없습니다.
업로드·교체·삭제·이름 바꾸기는 확인된 개인 프로젝트에서만 됩니다. 프로젝트 ID는 사용자별로 다르며 고정값을 사용하지 않습니다.
허용 범위: 확장 아이콘에서 사용자가 저장한 두레이 사이트에서 로그인한 브라우저로 확인한 개인 프로젝트입니다. 공유 프로젝트는 연결하지 않습니다.
개인 프로젝트 ID는 cowork 사용자별 연결에 저장합니다. 연결을 해제하거나 새로 연결하면 다시 확인합니다. 여러 개인 프로젝트가 감지되면 연결할 탭만 남기고 새로고침하세요.
0.5.0 이하 확장은 업데이트해야 합니다. 두레이에서 다른 계정으로 로그인했다면 해당 개인 프로젝트를 열고 cowork 드라이브를 새로고침하세요.
두레이 웹사이트의 요청을 사용하므로 사이트가 바뀌면 어댑터 수정이 필요합니다.
파일 한도는 50MiB와 서버 첨부 제한 중 작은 값입니다. 개인 보관 파일은 50개·파일 한도의 5배까지입니다.
현재 폴더의 한 쪽만 읽으며 전체 드라이브를 순회하지 않습니다. 교체는 revision을 검사하고 원격 변경이 있으면 중단합니다.
전송이 끊겼거나 결과를 확인하지 못했을 때는 자동으로 다시 쓰지 않습니다. 두레이에서 결과를 확인하세요.

두레이 주소 설정: 확장 아이콘에서 https://team.dooray.com 또는 https://team.gov-dooray.com 같은 본인의 두레이 기본 주소를 저장하고 해당 사이트 접근 권한을 허용하세요. 기존 버전에서 갱신한 경우에도 주소를 저장한 뒤 cowork 서버를 다시 연결해야 합니다. 기관 주소는 배포본에 고정하지 않습니다.
