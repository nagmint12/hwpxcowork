# 표준서식 문서 작성 지침 — AI 용(제안·메모로 고칠 때)

이 문서는 대학혁신센터 **표준서식**(스킬 `hwpx-standard-report`)으로 만든 보고서다. 서식은 문서 안의 **스타일을 빌려 쓴다** —
글꼴·크기·줄 간격을 하나하나 정하지 말고, 새 문단·고친 문단에는 아래 **역할 스타일**을 준다(`propose_format`·`propose_insert` 의
`format.styleId` — 스타일 번호는 `get_formatting` 으로 이름을 보고 고른다). 서버 MCP 도구로 제안하고, 반영·거절은 사람이 한다.

## 1. 문단 역할 → 스타일

| 역할 | 스타일 이름 | 쓰는 곳 |
|---|---|---|
| 문서 제목 | `&본문제목` | 본문 첫 쪽 맨 위 하나 |
| 장 | `&본문 1.` | `1. 사업 개요`, `부록` |
| 절·소절 | `&본문1)` | `1) 추진 배경`, `가. 자료` |
| 본문(■) | `&■…`(글머리표 1) | 단락의 첫 문장·요약. 앞에 `(배경)` 같은 라벨은 굵게 |
| 하위 항목(◦) | `&◦…`(글머리표 2) | 본문 아래 항목 |
| 세부(-) | `&-…`(글머리표 3) | ◦ 아래 세부 |
| 단위 줄 | `&표단위` | 표 바로 앞 `(단위: 명, %)` — 오른쪽 정렬 |
| 표·그림 주석 | `&표주석` | `주: …`, `주1: …` |
| 빈 줄·캡션 | `바탕글` | 빈 문단, 표·그림 캡션 |

- 글머리 기호(■ ◦ -)는 **글자로 쓰지 않는다** — 스타일의 글머리표가 붙인다. 번호(`1.`·`1)`)는 장·절 제목 글에 그대로 쓴다.
- 이름에 사설 글자가 섞인 스타일(■)은 `get_formatting` 에서 이름 앞부분(`&`)과 글머리표 번호로 고른다.

## 2. 빈 줄과 쪽

- **장 제목 앞에 빈 줄 하나**(새 쪽에서 시작하는 2장부터는 쪽 나누기가 대신한다). 문서 제목 바로 뒤의 1장은 빈 줄 없이, 제목 아래 도입 문단 뒤면 빈 줄 하나.
- **절 제목 앞에 빈 줄 하나**(장 제목 바로 뒤의 첫 절은 빈 줄 없음). 장·절 제목 **뒤에는** 빈 줄을 두지 않는다.
- 표·그림 뒤에는 `바탕글` 빈 문단 하나(주석이 있으면 주석 뒤). 그 바로 뒤 절 제목 앞에 빈 줄을 겹쳐 넣지 않는다.
- 빈 줄은 `propose_insert(after_ref, blank=true)`(글 없이 — 서식을 주지 않으면 `바탕글`)로 넣고, 이유에 「장 제목 앞 빈 줄」처럼 규칙을 적는다.
  공백 한 칸짜리 문단으로 빈 줄을 흉내 내지 않는다. 빈 줄을 지우는 것은 사람이 편집기에서 한다.
- **여러 문단은 문단 추가로** 낸다 — 장·절·본문 문단마다 `propose_insert` 하나(역할 스타일을 format 으로). 긴 글 전체를 제안 하나의
  `replace`·`text` 에 몰아넣지 않는다. 그 안의 줄바꿈은 줄마다 새 문단(빈 줄은 빈 문단)이 되지만 스타일은 모두 같아진다.

## 3. 문장

- 문서의 **지금 문체**(`…하였다`·`…함/…임` 개조식 등)를 그대로 따른다. 한 단락 안에서 섞지 않는다.
- 추측 표현(`…로 보인다`, `…할 것으로 판단된다`)은 근거가 있으면 단정형으로, 없으면 근거를 묻는 메모로.
- 숫자: 천 단위 구분(`17,716`), 비율 소수 1자리(`53.2`), 계수·평점 2~3자리, 부호 있는 변화량은 `+1.51`/`−0.16`(유니코드 마이너스),
  p값 `.003`·`<.001`, 신뢰구간 `[0.53, 0.57]`, 결측·해당 없음 `–`. 숫자는 첨부·문서에 근거가 있을 때만 넣는다.
- 같은 통계량·같은 열은 소수 자릿수를 통일하고 **끝자리 0을 유지**한다. 별도 기준이 없으면 평점·평점변화·표준편차·t값은
  소수 2자리(`0.7` → `0.70`, `3.0` → `3.00`), 비율(%)은 1자리(`46.0`)로 쓴다. 평점·표준편차처럼 1을 넘을 수 있는 값은
  1 미만이어도 앞의 0을 표시한다. 인원·건수는 정수, 연도·식별자에는 천 단위 쉼표를 넣지 않는다.
- p값은 일반 계수와 구분해 소수 3자리 또는 `p < .001`로 보고한다. 반올림된 `p = .000`은 `p < .001`로 고친다.
  결측 기호를 숫자로 바꾸지 않는다. **0을 덧붙이는 표기 정리와 원자료로 재계산하는 작업을 구분**한다.
  `0.7`만 있는 곳을 `0.70`으로 표기할 수 있지만 근거 없이 `0.69` 등으로 바꾸지 않는다. 더 정밀한 원자료가 필요하면 메모로 요청한다.
- 본문의 표·그림 번호(`[표 3]`)는 문서의 **지금 번호**를 `read_document` 로 확인해 쓴다(자동 번호는 배치 순서로 다시 매겨진다).

## 4. 표·그림

- **표**(`propose_table`): `caption` 은 제목 글만(번호 없이 — 문서에서 `[표 N] 제목` 자동 번호), 캡션은 표 **위**. 머리행 1줄(두 줄이면
  `header_rows=2`), 칸 글은 짧게. 표 앞에 단위 줄 `(단위: …)`, 표 아래 주석 `주: …`(유의 표기는 `주: *p<.05, **p<.01, ***p<.001.`).
  정렬은 숫자 열 오른쪽·첫 열 왼쪽·나머지 가운데, ▲·▼ 증감은 서버가 빨강·파랑으로 둔다. 테두리·음영은 문서의 표 모양을 따른다
  (바꾸려면 `propose_table_edit` — 머리행 위 실선 0.5·아래 이중선 0.5·음영 #BFBFBF, 첫 열 왼쪽·끝 열 오른쪽 선 없음).
- **그림**(`propose_figure`): 캡션은 그림 **아래** `[그림 N] 제목`(제목 글만 준다), 그림 안에 제목을 넣지 않는다. 폭은 본문 폭(약 150mm) 이하.
- 표 폭은 본문 폭(42,240 HWPUNIT ≈ 149mm)을 넘지 않는다.

## 5. 차례

- 차례는 `propose_toc_update`(새로 고침) — `apply_styles` 로 `<제목 차례>`·`<표 차례>`·`<그림 차례>` → 차례제목, 장(1.·부록)·표·그림 항목 → 차례1,
  절(1)) → 차례2. 차례1·차례2 는 한 줄로 입력(넘치면 자간을 줄여 한 줄). 차례 문단에 `propose_format` 을 하지 않는다(새로 고치면 다시 만들어진다).

자세한 수치(문단 간격·글꼴·테두리 번호)는 `get_writing_guide(part='spec')`(서식명세).
