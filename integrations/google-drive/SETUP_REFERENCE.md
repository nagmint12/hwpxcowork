# 보관용 Google Drive 설정 안내

현재 제품에서 비활성화한 기능의 과거 안내입니다. 배포 확장에는 포함되지 않습니다.

## 구글 드라이브

구글 드라이브는 공식 Drive API를 사용한다. 확장의 연결 실행 창에서 Google OAuth 클라이언트 ID를 등록하고 계정을 연결한다.

1. Google Cloud 프로젝트에서 Google Drive API를 활성화하고 OAuth 동의 화면을 설정한다.
2. 웹 애플리케이션 OAuth 클라이언트를 만들고 연결 실행 창에 표시된 `https://<확장-ID>.chromiumapp.org/`를 승인된 리디렉션 URI에 등록한다. 미게시 앱이면 사용하는 계정을 테스트 사용자로 등록한다.
3. 클라이언트 ID를 입력하고 **구글 계정 연결**을 누른다. 파일 목록 탐색 및 기존 파일 수정용 `drive` 범위를 사용하므로 조직 정책에 따라 관리자 승인이 필요할 수 있다.

Google 토큰은 확장의 브라우저 세션 저장소에만 두고 cowork 서버로 보내지 않는다. 만료 시 다시 연결한다. 현재 지원 범위는 내 드라이브의 폴더 탐색, 일반 파일 업로드·교체, 일반 파일 다운로드 및 Google 문서(docx)·시트(xlsx)·슬라이드(pptx)·그림(pdf) 내보내기다. Google 문서 원본 교체와 공유 드라이브 목록 탐색은 지원하지 않는다. 업로드는 resumable 세션으로 수행하고 세션 URL의 출처를 재검사한다. 일반 파일 교체는 version을 비교하고 응답에 ETag가 있으면 If-Match도 보낸다.

실제 Google OAuth 계정 연결은 클라이언트 설정이 없어 실행하지 않았다. 모의 HTTP 응답으로 목록·다운로드·버전 충돌·업로드 세션을 검증했다.
