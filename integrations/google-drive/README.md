# Google Drive 연동 — 별도 보관

2026-10-29 사용자 요청으로 제품에서 제외했다. 현재 제공 기능은 두레이 개인 프로젝트뿐이다.

- `extension/google.js`: OAuth 및 목록·다운로드·업로드 어댑터 원본
- `extension/settings.*`, `extension/support.js`: 확장 계정 설정·지원 여부 검사
- `provider.js`: 공급자 정보·확장 권한·대상 검사·커서 페이지 이동
- `SETUP_REFERENCE.md`: 과거 설정 안내와 당시 지원 한계
- `tests/adapter.test.mjs`: 모의 HTTP 어댑터 검증(현재 제품 테스트와 별도)

이 폴더는 웹 정적 제공 경로와 확장 ZIP에 포함하지 않는다. 서버 공급자 허용 목록·API·AI 문맥에서도 비활성 공급자를 거절한다. 기존 Google 계정 권한을 해제하거나 기존에 가져온 문서·파일을 삭제하지 않는다.

다시 제공하려면 OAuth 흐름·브라우저 호환성·파일 작업을 별도로 완성하고 서버 허용 목록, 웹 선택 UI, 확장 작업 분기·설정 화면, manifest 권한, 패키징을 함께 복구해야 한다. 계정이 실제 연결되는 검증 전에는 배포에 포함하지 않는다.
