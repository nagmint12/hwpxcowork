HWPX 문서를 함께 고치는 편집기

한/글 문서(HWPX·HWP)를 브라우저에서 열어 고치고, 여러 사람과 AI가 낸 수정 제안을 검토해 반영합니다.

브라우저에서 편집기 열기 →

이 페이지의 체험 편집기

  • 내 파일만, 내 브라우저 안에서PC에 있는 HWP·HWPX 파일을 열어 고치고 저장합니다. 문서는 이 브라우저 안에서만 처리되고 어디에도 올라가지 않습니다.
  • API 키는 저장하지 않습니다편집기의 AI 도우미에 넣은 API 키는 이번 실행 동안만 쓰고, 새로 고치거나 창을 닫으면 지워집니다. 이 공개 페이지는 키를 브라우저 저장소에 남기지 않습니다.
  • 함께 쓰기는 설치판에서공동 검토, 문서함, AI 작업(수정 제안·메모)은 Windows 앱이나 서버에 설치한 판에서 씁니다.

할 수 있는 것

함께 검토

같은 문서를 여러 사람이 고치고, 바뀐 곳과 메모를 문서 위에서 주고받습니다.

AI 수정 제안

ChatGPT·Claude·Gemini 같은 내 AI가 낸 제안을 문서에 표시하고 [반영]·[거절]로 고릅니다.

한/글 기준 조판

한/글 2022 출력을 기준으로 쪽·줄·표·그림 배치를 맞춥니다. 저장한 HWPX는 한/글에서 다시 열 수 있습니다.

여러 기기

Windows 앱(편집·함께 쓰기·AI 실행기), Mac 편집기, Android 편집기가 있습니다.

편집기 엔진은 rhwp(MIT)를 바탕으로 합니다. 한글과컴퓨터의 한글 문서 파일 공개 문서를 참고했습니다.
