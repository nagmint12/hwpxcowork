한/글 기준 조판

한/글 2022 출력을 기준으로 쪽·줄·표·그림 배치를 맞춥니다. 저장한 HWPX는 한/글에서 다시 열 수 있습니다.

여러 기기

Windows 앱(편집·함께 쓰기·AI 실행기), Mac 편집기, Android 편집기를 GitHub 릴리스에서 받습니다.

문서는 이 브라우저 안에서만 처리되고 어디에도 올라가지 않습니다. 이 페이지는 API 키·접속 토큰을 받지도 저장하지도 않습니다.

편집기 엔진은 rhwp(MIT)를 바탕으로 합니다. 한글과컴퓨터의 한글 문서 파일 공개 문서를 참고했습니다.
