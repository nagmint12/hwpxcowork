HWPX Cowork

개인정보처리방침

HWPX Cowork 프로젝트(nagmint12)는 문서를 여는 위치와 사용자가 선택한 기능에 따라 다음과 같이 데이터를 처리합니다. 이 방침의 작성일은 2026년 11월 23일입니다.

개인 웹 편집기에 보관되는 정보

열거나 만든 문서의 파일명·본문, 편집 내용, 메모와 튜토리얼 진도는 현재 브라우저의 사이트 저장소(IndexedDB)에 보관합니다. 로컬 파일을 여는 동작으로 그 파일을 프로젝트 운영자에게 전송하지 않습니다. 공개 웹사이트는 GitHub Pages가 제공합니다. 사이트 접속에 따른 정보 처리는 GitHub 개인정보처리방침에서 확인할 수 있습니다.

Google Drive에서 선택한 문서

Drive 연결은 준비 중이며, 이 항목은 연결 기능이 제공된 버전에서 사용자가 Google에 동의하고 직접 선택한 파일에 적용됩니다. Google 파일 선택기(Picker)와 drive.file 권한을 사용합니다. 선택한 HWPX를 열기 위해 파일 ID·이름·형식·편집 가능 여부와 파일 내용을 읽습니다. 원본에 저장할 때는 편집 결과를 Google Drive의 같은 파일 ID로 보냅니다.

Google이 발급하는 액세스 토큰은 파일 접근 권한을 확인하는 데 사용합니다. Drive 연결만으로 파일을 공동 서버나 AI 제공자에게 전달하지 않습니다. 프로젝트는 Google에서 받은 데이터를 판매하거나 광고 또는 범용 AI 모델 학습에 사용하지 않습니다. Google 데이터의 이용과 이전에는 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 따릅니다.

공동 서버와 선택형 AI

설치판에서 공동 서버로 문서를 올리면 해당 서버가 문서와 검토 기록을 보관하며 문서함 권한에 따라 참여자가 볼 수 있습니다. AI 검토를 별도로 요청하면 연결한 실행기 또는 AI 제공자가 요청문과 작업에 필요한 문서 내용·첨부를 처리할 수 있습니다. 어느 서버와 제공자를 사용하는지는 해당 설치의 설정에서 확인할 수 있습니다.

보관 기간, 삭제와 연결 해제

개인 웹 문서함의 문서는 삭제하거나 브라우저의 해당 사이트 데이터를 지울 때까지 보관됩니다. 보관할 편집본은 먼저 ‘한글로 저장’으로 내려받으세요. 내려받은 파일은 기기의 파일 관리자로 삭제할 수 있습니다. 공동 서버의 문서와 백업 보관·삭제는 해당 서버 관리자에게 문의하세요.

Drive 연결 후에는 Google 계정의 서드 파티 연결에서 HWPX Cowork의 권한을 해제할 수 있습니다. 권한 해제 후에도 Drive 원본과 이미 저장한 편집본은 각각 남습니다. Drive 파일과 버전은 Google Drive에서 관리할 수 있습니다.

개인정보 문의

방침이나 삭제 방법에 관한 일반 문의는 HWPX Cowork 프로젝트 문의에서 받습니다. 공개 게시판에는 문서나 계정 정보, 인증 키를 첨부하지 마세요. 개별 자료가 필요한 경우 먼저 비공개 연락 방법을 요청해 주세요.
