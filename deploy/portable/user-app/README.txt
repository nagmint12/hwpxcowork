hwpx-cowork 사용자 앱 (Windows)
================================

공동 검토 서버의 편집 화면을 주소창 없는 앱 창(Edge 또는 Chrome)으로 여는 작은 바로 가기입니다.
Node.js·서버·편집기를 설치하지 않습니다. 서버를 켜고 끄는 일은 관리자 앱에서 관리자가 합니다.

1. server-url.txt 에 관리자에게 받은 서버 주소가 적혀 있는지 확인합니다(관리자 앱에서 만든 파일이면 이미 들어 있음).
2. hwpx-cowork.bat 를 두 번 누르면 앱 창이 열립니다. 처음에는 관리자에게 받은 본인 토큰으로 로그인합니다.
3. make-shortcut.bat 를 한 번 실행하면 바탕 화면에 'hwpx-cowork' 바로 가기가 생깁니다. 그다음부터는 그 아이콘만 누르면 됩니다.

인터넷에서 받은 ZIP 이면 먼저 ZIP 파일 [속성] → '차단 해제' 를 체크한 뒤 풉니다.
Edge 에서 직접 하려면: 서버 주소를 열고 [… → 앱 → 이 사이트를 앱으로 설치] 를 눌러도 같습니다.
