설치 안내 (Windows · macOS · Linux)
===================================
이 묶음에는 Node 런타임과 npm 라이브러리가 들어 있지 않습니다. 실제로 쓸 PC에서 인터넷에 연결해 설치합니다.

Windows: ZIP 해제 → install.bat 더블클릭
  Node.js 22 이상이 없으면 공식 Node.js와 npm을 runtime\에 받습니다(SHA-256 확인, 관리자 권한 불필요).
macOS/Linux: 압축 해제 후 sh install.sh

라이브러리는 app\package-lock.json 기준으로 설치합니다(npm ci --omit=dev --ignore-scripts).
설치가 실패하면 실행하지 않습니다. 네트워크·프록시를 확인한 뒤 다시 설치합니다.
