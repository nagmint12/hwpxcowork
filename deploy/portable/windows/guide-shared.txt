hwpx-cowork 공동 작업용 (Windows) 설치 안내
=========================================

이 PC를 서버로 삼아 여러 사람이 같은 HWPX 문서를 함께 고칩니다.
참여자는 프로그램을 설치하지 않고 브라우저로 접속합니다.
- 실시간 공동 편집, 메모·답글
- 변경 내용 추적: 고친 부분이 제안으로 남고 [반영]·[거절]로 확정
- 사용자별 토큰, 폴더별 열람·편집 권한
- [한글로 저장]으로 HWPX 파일 내려받기

필요한 것
- 서버로 쓸 Windows 10·11 PC (64비트). 함께 작업하는 동안 켜 둡니다.
- 처음 설치할 때 인터넷. 외부 참여자가 접속할 때도 인터넷이 필요합니다.
- 관리자 권한은 필요 없습니다.

설치와 실행 (서버 PC)
1. ZIP을 원하는 곳에 압축 풀기
2. 시작.bat 더블클릭
   - 처음 한 번 Node.js와 라이브러리를 받습니다(2~5분).
   - 준비되면 관리자 계정으로 문서함이 열립니다.
3. 다음부터는 시작.bat만 실행하면 됩니다.
4. 끌 때: 종료.bat

참여자 추가
1. 문서함 위쪽 [관리자] → [사용자] → 이름 입력 → [추가]
2. 한 번만 보이는 토큰을 [복사]해 그 사람에게만 전달합니다.
   (토큰을 잃어버리면 [토큰 바꾸기]로 새로 만듭니다.)

참여자 접속
1. 서버 PC에서 외부 접속 열기.bat 실행
   - 처음에는 Cloudflare의 무료 터널 프로그램(cloudflared)을 이 폴더 tools\에 받습니다. 계정은 필요 없습니다.
   - 창에 https://…trycloudflare.com 주소가 나옵니다.
2. 참여자는 브라우저(Chrome·Edge·Safari 등)로 그 주소에 접속해 받은 토큰을 입력합니다.
- 외부 접속 열기.bat 창을 켜 둔 동안만 접속됩니다. 열 때마다 주소가 바뀝니다.
- 늘 같은 주소로 운영하려면 고정 도메인과 HTTPS가 필요합니다: app\docs\DEPLOYMENT_AND_AI_GUIDE.md

문서 작업
1. 문서함 [＋ HWPX 올리기]로 문서를 올립니다.
2. 폴더를 만들어 참여자별로 볼 수 있는 범위와 권한을 정합니다.
3. 문서를 열면 함께 고치는 내용이 바로 보입니다. 마친 뒤 [한글로 저장]으로 내려받습니다.

AI 연결 (선택)
- 관리자: AI 연결.bat 실행 → ChatGPT 구독(Codex) 또는 Claude 구독(Claude Code) 선택 → 본인 계정으로 로그인.
  연결한 AI는 관리자 본인의 요청을 처리합니다.
- 참여자: 각자 문서함의 [AI 연결]에서 본인 AI를 연결합니다.
- API 키·유료 API는 쓰지 않습니다.

폴더 구성
- 설정·문서·편집 기록: app\userdata-shared\  (백업할 때 이 폴더를 복사합니다)
- Node.js: runtime\   라이브러리: app\node_modules\   cloudflared: tools\
- 지우기: 종료.bat 실행 뒤 이 폴더를 통째로 지웁니다. 서버에 올린 문서도 함께 지워지므로 먼저 내려받아 둡니다.

문제가 생기면
- 시작.bat 창에 오류가 보이면 인터넷·프록시를 확인한 뒤 다시 실행합니다.
- 참여자가 접속하지 못하면 외부 접속 열기.bat 창이 켜져 있는지, 창에 나온 주소가 맞는지 확인합니다.
