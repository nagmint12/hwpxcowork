hwpx-cowork 개인용 앱 (Windows 10/11 · Linux · macOS)
====================================================

내 PC 폴더의 HWPX(한글) 문서를 열어 고치고, 메모·변경 추적·AI 제안으로 검토하는 앱입니다.
중앙 서버에 접속하지 않습니다 — 이 PC 에서만 열리는 서버가 앱 안에서 돌고, 문서는 내 PC 폴더의 파일 그대로입니다.
여럿이 모여 검토할 때만 문서를 중앙 서버로 보내고, 검토가 끝나면 검토본을 내 PC 파일로 가져옵니다.
npm·Rust·한글 프로그램을 설치하지 않아도 됩니다. 미리 빌드한 편집기·엔진(WASM)이 들어 있습니다.

0. Node.js
   - 이 PC 에 Node.js 22 이상이 있으면 그것을 씁니다.
   - 없으면 처음 켤 때 "공식 Node.js 를 이 폴더 runtime\ 에 내려받을까요?" 라고 묻습니다(약 30 MB, 관리자 권한 불필요,
     nodejs.org 공식 파일의 SHA-256 을 확인). 미리 받으려면 install-node.bat.

1. 켜기
   - 인터넷에서 받은 ZIP 이면 먼저 ZIP 파일 [속성] → '차단 해제'를 체크한 뒤 풉니다. 한글·공백이 든 경로도 됩니다.
   - personal-app.bat 를 두 번 누릅니다(Linux·macOS: ./personal-app.sh).
   - 처음에는 폴더 고르기 창이 뜹니다. HWPX 가 든 폴더(예: 문서\보고서)를 고르면 그 폴더가 연결됩니다.
     폴더를 personal-app.bat 위에 끌어다 놓아도 됩니다. 나중에 문서함의 [PC 폴더 연결]로 더 연결하거나 끊습니다.
   - 앱 창(Edge·Chrome 의 주소창 없는 창)이 열립니다. 로그인은 필요 없습니다.
   - 앱은 작업 표시줄의 최소화된 창으로 돕니다. 앱 창을 닫으면 함께 꺼집니다(그 창을 닫아도 꺼집니다).

2. 내 PC 폴더의 문서
   - 문서함 왼쪽 '개인 문서함' 아래에 연결한 폴더(PC 표시)와 그 하위 폴더가 탐색기와 같은 모양으로 보입니다.
     HWPX 가 있는 폴더와 빈 폴더만 보입니다.
   - 문서를 열어 고치면 잠시 뒤 그 파일에 저장됩니다(문서 화면 위의 'PC' 표시에 마우스를 올리면 저장 시각).
     저장되는 파일은 한/글에서 그대로 열립니다(메모·변경 추적 포함).
   - 한/글에서 그 파일을 고쳐 저장하면 앱이 다시 읽습니다. 같은 문서를 양쪽에서 고쳤으면 PC 파일이 기준이 되고,
     앱에서 고친 내용은 문서의 [이력]에 남아 되돌릴 수 있습니다.
   - 한/글에서 열어 둔 동안에는 앱이 그 파일에 쓰지 못합니다('PC 쓰기 대기'). 한/글에서 닫으면 저장합니다.
   - 새 문서·올리기·이름 바꾸기·옮기기·폴더 만들기는 PC 폴더에 그대로 반영됩니다. 지운 문서의 파일은 휴지통으로 갑니다.
   - 탐색기에서 파일을 옮기거나 이름을 바꿔도 내용이 같으면 같은 문서(이력 포함)로 이어집니다.
   - [연결 끊기]는 문서함에서만 뺍니다. PC 의 파일과 앱의 기록은 그대로 남고, 같은 폴더를 다시 연결하면 이어집니다.

3. 모여서 검토하기(중앙 서버)
   - 문서함의 [검토 서버]에 중앙 서버 주소와 그 서버에서 받은 내 토큰을 한 번 등록합니다(토큰은 이 PC 에 암호화해 저장).
   - 문서 줄의 [함께 검토](위쪽 화살표)를 눌러 [보내기] — 지금 문서가 그 서버에 새 문서로 올라갑니다.
     [서버에서 열기]로 그 서버의 문서를 열어 여럿이 검토합니다(그 서버에서 폴더·권한으로 공유).
   - 검토가 끝나면 [검토본 가져오기] — 서버의 검토본이 내 문서와 PC 파일에 들어옵니다(그 전 내용은 이력에 남음).
   - 중앙 서버를 브라우저로 바로 열어 쓰는 것도 예전과 같습니다(주소 + 토큰).

4. AI
   - 문서함의 [내 AI 키]에 API 키를 등록하면 이 앱이 내 요청을 그 키로 처리합니다.
   - ChatGPT(Codex)·Gemini CLI 로그인으로 처리하려면 실행기를 함께 켭니다:  personal-app.bat --ai "--provider codex"
     (매번 켜려면 userdata-personal\config.json 의 "personal": { "app": true, "ai": "--provider codex" })
   - Claude Code 등 MCP 클라이언트: 주소 http://localhost:<포트>/mcp, 토큰은 userdata-personal\config.json 의 users[0].token
     (포트는 최소화된 창의 '켜짐' 줄에 보입니다 — 기본 8790)

5. 폴더
   personal-app.bat / personal-app.sh / install-node.bat
   app\                프로그램(고치지 않습니다 — 업데이트 때 통째로 바뀝니다)
   userdata-personal\  첫 실행 때 생김: config.json(설정·내 토큰), data\(문서 기록·이력), browser\(앱 창 프로필)
                       문서 파일 자체는 연결한 PC 폴더에 있습니다. 이 폴더를 지워도 PC 의 문서는 남습니다(이력·메모 묶음·AI 작업 기록은 사라짐).
   NOTICES\            제삼자 라이선스 고지
   업데이트: 앱을 끄고 새 ZIP 의 app\·*.bat 를 덮어씁니다. userdata-personal\ 는 그대로 둡니다.

6. 알아 둘 것
   - 이 PC 에서만 접속됩니다(127.0.0.1). 다른 사람이 내 PC 의 앱에 접속하게 하려면 서버 묶음(hwpx-cowork-server)을 쓰세요.
   - 문서 이름·작성자: 메모와 변경 추적에 남는 이름은 처음 켤 때의 Windows 사용자 이름입니다
     (personal-app.bat --name "홍길동" 으로 처음 켜거나, 앱의 [관리자] → 사용자에서 바꿉니다).
   - 클라우드 동기화 폴더(OneDrive 등)를 연결해도 됩니다. 고치는 동안 파일이 1~2초마다 다시 저장됩니다.
