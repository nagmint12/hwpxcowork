# 보고서 작성 규칙(예시)

'내 skill을 그대로 쓴다'를 보여 주려고 만든 짧은 예시입니다. 실제 기관의 규칙이 아닙니다.
이 파일을 요청에 첨부하면 연결한 AI가 `read_skill_resource` 로 읽고 아래 규칙대로 씁니다.

## 규칙

1. 문장은 개조식으로 '~함', '~임', '~음'으로 끝낸다.
2. 시사점·제언마다 근거가 된 표·그림의 이름을 괄호에 적는다. 예: (근거: 「원 등급별 재수강 평점변화」 표)
3. 기술통계만으로 인과를 단정하지 않는다. 한계는 같은 문장 안에 적는다.
4. 새 절을 넣었으면 마지막에 차례를 새로 고친다.

## 쓰는 자리

- 시사점과 정책제언은 각각 세 개 안팎으로, 본문 문단 뒤에 목록 문단으로 넣는다.
- 절 제목은 문서의 다른 절 제목과 같은 스타일을 쓴다.
